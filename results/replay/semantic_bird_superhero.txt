Conventions (4)
1. This database is SQLite. Use SQLite syntax and functions: STRFTIME for dates, || for string concatenation, CAST(x AS FLOAT) for ratios.
2. Query read-only with one SELECT or WITH statement and no trailing semicolon.

Gotchas (3)
1. Integer division truncates: CAST one side to FLOAT before dividing.
2. Some columns store dates as TEXT; compare them as strings in YYYY-MM-DD form.
3. NULL values never equal anything; use IS NULL or IS NOT NULL to test them.
